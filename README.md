# S2 CES Project Learning Guide

A bilingual (English primary / Chinese secondary) self-learning webpage for **Secondary 2 Citizenship, Economics and Society** project work.

Built as a learning guide for students at **SKH Bishop Baker Secondary School**. It follows the school’s project phases for practice and organisation.

**Not** an official marked portal or final assessment script. Teachers still mark according to school guidelines.

Open `index.html` locally, or use the GitHub Pages site linked from this repository.
